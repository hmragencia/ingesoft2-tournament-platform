# 6. Use of artificial intelligence and references

## 6.1 Use of artificial intelligence

- **Claude Code (Anthropic, model Claude Opus 5.5).** It drafted the written sections of this workshop: system domain, CRC cards, class diagram, relational model and the mockup prompt. It worked from the Workshop 1 deliverables (requirements, user stories and story map), the approved project proposal and the documentation of the existing tournament-management platform, so that the design reuses the real tables and views. The team reviewed and adjusted every section before submission.
- **v0 by Vercel.** It generated the clickable prototype used for the mockups, from a template, the reference image sent by the organization and the prompt in [v0-prompt.md](v0-prompt.md).
