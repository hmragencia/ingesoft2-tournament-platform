# 5. Uso de inteligencia artificial

Este documento fue elaborado con Claude Code, usando el modelo Claude Opus 5.5 de Anthropic, a partir de las notas de una reunión del grupo en la que se definió el alcance del proyecto: trabajar el módulo público del torneo (página web, widgets y aplicación) y proyectarlo hacia funciones comerciales.

Con esas notas como base, la herramienta nos hizo preguntas una a una sobre el alcance, el idioma, el contenido que vería el público, las funciones comerciales, los canales, los roles, los releases y la extensión. Con nuestras respuestas redactó los requisitos, las historias de usuario y el mapa, y el grupo revisó el resultado antes de entregarlo.
